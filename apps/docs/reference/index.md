# API Reference

The reference documents the public API by responsibility rather than by source file.

- [ORM and Schema API](/reference/schema): constructors, `schema`, `objectId`, `ref`, and registries.
- [Database and Models](/reference/models): `createDatabase`, connection lifecycle, models, and CRUD methods.
- [Query API](/reference/queries): query builders, cursor pages, selection, population, and counts.
- [Errors](/reference/errors): runtime error classes and failure conditions.

Use the guides first when learning Mongorm. Use this section when you already know what you want to call and need exact signatures or constraints.
